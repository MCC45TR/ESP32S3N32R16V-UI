<h4>QSPI Servisindeki Mevcut Fiziksel Durum</h4><ul>
<li>ESP32-S3 endpoint'i artik <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">quad-ready</code>/<code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">classic</code> modunu runtime secer. <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">PIN_SPI_WP</code> ve <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">PIN_SPI_HD</code> atanmadiysa klasik 1-bit SPI (<code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">quadwp_io_num=-1</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">quadhd_io_num=-1</code>) kullanilir.</li></ul>
<ul>
<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">PIN_SPI_WP</code>/<code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">PIN_SPI_HD</code> atanirsa bus 4-bit lane pinleriyle acilir (<code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">quad-ready-4bit</code>), ancak master tarafindaki fiziksel 4-bit yol yine ayri dogrulama ister.</li></ul>
<ul>
<li>Teensy tarafinda <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">kFlexioQuadDmaDriverActive=false</code> iken sync <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">SPI1</code> fallback devreye girer ve <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">SCK=2</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">IO0=3</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">IO1=4</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">CS=6</code> hatlariyla transfer baslatir.</li></ul>
<ul>
<li>Gercek 4-bit QuadSPI DMA (IO0/IO1/IO2/IO3) hatti halen <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">driver=pending</code> durumundadir.</li></ul>


<h3 style="color:#4db8ff;">Guvenli Bring-up Sirasi</h3>

1. Sadece UART1/Serial5 ve GND bagla.
2. Iki karti da USB'den ayri ayri besle veya ortak power planini dogrula; 5 V tolerant varsayma.
3. ESP32-S3 shell'de <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">set uart-shell-bridge listen</code> veya gereken test icin <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">set uart-shell-bridge on</code> kullan.
4. Teensy USB mshell'de <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">uart status</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">mshell status s3</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">mshell connect s3</code> komutlariyla sayaçlari kontrol et.
5. SPI uyumluluk testi icin ek olarak su baglantiyi yap: ESP32 <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">GPIO12(SCK)->T41 pin2</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">GPIO11(MOSI)->T41 pin3</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">GPIO13(MISO)<-T41 pin4</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">GPIO10(CS)<->T41 pin6</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">GPIO14(ESP_READY)->T41 pin9</code>, <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">GPIO15(T41_READY)<-T41 pin8</code>.
6. Realtime 4-bit QuadSPI beklentisini simdilik acma; bu adim icin FlexIO1 DMA yolunun ayrica dogrulanmasi gerekiyor.

<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">spi test [--duration 10] [--json]</code></li></ul>
<ul>
<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">uart test [--duration 10] [--json]</code></li></ul>
<ul>
<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">robot diag linktest [uart|qspi|all] [--duration 10] [--json]</code></li></ul>


Teensy tarafinda esit komutlar:<ul>
<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">comm qspi test [--duration 10] [--json]</code></li></ul>
<ul>
<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">comm qspi clock status|suggest|set <hz>|apply-suggested [--yes] [--json]</code></li></ul>
<ul>
<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">uart test [--duration 10] [--json]</code></li></ul>
<ul>
<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">devices test p4|uart|s3-uart|all [--json]</code></li></ul>


Not:<ul>
<li><code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">c3</code> hedefi bu topolojide devre disidir; eski alias cagrilarinda komut acikca <code style="background:#333;padding:2px 4px;border-radius:3px;color:#e83e8c;">disabled</code> doner.</li></ul>


Varsayilan test ciktilari:<ul>

<ul>

<ul>
